# depths_function
Depths functions apply to weather data


**Loan** pour commencer le projet j'ai vu un uv init (ca gère tes extensions et les installations des packages)

pour commencer dans ton terminal tu lances cette commande : ``pip install uv``

puis ensuite tu peux faire uv init si tu l'as jamais fait ou uv sync et quand tu veux installer un nouveau pacakge tu fais ``uv add <nom_pacakage>``
ex : 
``
uv add pandas
``


Si tu veux faire tourner l'EDA, tu peux lancer cette commande : 

uv run python -m test_eda.main
